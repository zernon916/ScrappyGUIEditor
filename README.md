# Scrappy GUI Editor

Local visual editor for Scrap Mechanic `.layout` files.

GitHub: https://github.com/zernon916/ScrappyGUIEditor

Open `scrap_gui_editor\start_editor.bat` (or this folder’s `start_editor.bat`) to launch.

See `scrap_gui_editor\README.md` for the inspected MyGUI format, features, and tests.
